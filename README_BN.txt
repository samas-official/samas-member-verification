SAMAS — বিনামূল্যের অনলাইন সদস্য যাচাই ব্যবস্থার প্রাথমিক ফাইল

এই প্যাকেজে আছে:
- index.html: সদস্য যাচাইয়ের ওয়েব পেজ
- data/members.json: সদস্যদের প্রকাশযোগ্য তথ্যের ডেটা ফাইল

গুরুত্বপূর্ণ:
1) এটি এখনো অনলাইনে প্রকাশিত নয়; তাই এখনই বাস্তব QR তৈরি বা লাইভ যাচাই সম্ভব নয়।
2) আগে একটি বিনামূল্যের GitHub অ্যাকাউন্ট খুলে নতুন Public repository তৈরি করুন।
3) এই ZIP-এর ভেতরের ফাইলগুলো repository-তে আপলোড করুন।
4) Settings > Pages > Deploy from a branch > main / root নির্বাচন করে Save করুন।
5) GitHub Pages যে ওয়েব ঠিকানা দেবে, সেটিই হবে যাচাই পেজের ঠিকানা।
6) তারপর প্রতিটি কার্ডের QR-এ এই ঠিকানা + ?id=SAMAS-0001 এভাবে যুক্ত হবে।

সদস্য যোগ/পরিবর্তন:
data/members.json ফাইলে প্রতিটি অনুমোদিত সদস্যের জন্য একটি রেকর্ড যোগ করুন:
"SAMAS-0002": {
  "name": "সদস্যের নাম",
  "type": "সাধারণ সদস্য",
  "joined": "2026-11-26",
  "status": "active"
}
সক্রিয় সদস্যের status হবে active। স্থগিত/বাতিল হলে active নয় এমন মান দিন।

গোপনীয়তা ও নিরাপত্তা:
- NID, জন্মনিবন্ধন নম্বর, ফোন, বাসার ঠিকানা, ব্যক্তিগত ছবি, স্বাক্ষর, জরুরি যোগাযোগ বা আর্থিক তথ্য এই পাবলিক ফাইলে দেবেন না।
- ওয়েবসাইটটি Public হলে JSON-এ রাখা তথ্য যে কেউ দেখতে পারবে।
- প্রকৃত সদস্যের তথ্য প্রকাশের আগে সদস্যের সম্মতি এবং সংস্থার অনুমোদন নিন।
- এই প্রাথমিক সংস্করণে তথ্য সম্পাদনার জন্য লগইন/অ্যাডমিন প্যানেল নেই; শুধু repository-তে অনুমোদিত ব্যক্তিরা ফাইল আপডেট করবেন।
